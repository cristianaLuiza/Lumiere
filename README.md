# Lumiere

Lumiere é uma plataforma web de compartilhamento e doação de livros que conecta leitores interessados a pessoas dispostas a doar exemplares. Inspirado na dinâmica de aplicativos de interesse mútuo, o sistema permite que usuários demonstrem interesse em livros disponíveis e aguardem a aprovação do doador para realizar a troca.

O projeto foi desenvolvido com Angular no front-end e Spring Boot no back-end, utilizando APIs REST para comunicação entre as camadas e banco de dados relacional para armazenamento das informações.


## Principais Funcionalidades

* Cadastro e autenticação de usuários;
* Cadastro, edição e gerenciamento de livros;
* Busca e filtragem de obras disponíveis;
* Demonstração de interesse em livros;
* Gerenciamento de solicitações de doação;
* Interface responsiva e intuitiva.

## Tecnologias Utilizadas

* Angular
* TypeScript
* Java
* Spring Boot
* APIs REST
* MySQL / SQL Server
* Git e GitHub
* Docker

## Objetivo do Projeto

O Lumiere foi desenvolvido com o propósito de democratizar o acesso à leitura por meio da tecnologia, oferecendo uma plataforma digital capaz de conectar doadores e leitores de forma simples, segura e eficiente, contribuindo para a circulação de conhecimento e para o reaproveitamento de livros.
